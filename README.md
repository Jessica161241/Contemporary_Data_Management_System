## 📚 作业目录

本仓库包含项目开发的两个阶段，体现了系统的完整迭代演进：

### [Project 1 Phase 1：基于 MongoDB 的问卷系统开发](./Project_1)
- **阶段**：第一阶段
- **技术栈**：Python Flask + MongoDB + 原生 HTML/JS/CSS
- **核心功能**：
  - 用户注册、登录与 JWT 鉴权。
  - 问卷创建、状态管理（草稿/发布/关闭）。
  - 支持单选、多选、文本、数字四种题型。
  - **核心亮点**：基于 JSON 的动态跳转逻辑（`routing_rules`），支持防死循环检测。
  - **数据统计**：利用 MongoDB 聚合管道（Aggregation Pipeline）实现高效统计。
- **详细说明**：请查看 [Project 1 的 README 文档](./Project_1/README.md)。
- **测试报告**：请查看 [Project 1 测试用例与结果](./Project_1/测试用例.md)。

### [Project 1 Phase 2：题库与版本控制系统](./Project_1_phase2)
- **阶段**：第二阶段（需求变更迭代）
- **技术栈**：Python Flask + MongoDB + 原生 HTML/JS/CSS
- **核心功能**：
  - **题库管理**：支持将题目存入题库，并形成独立于问卷的版本树（v1, v2...）。
  - **快照隔离机制**：从题库导入问卷的题目采用深拷贝快照，题库修改绝对不影响已发布的旧问卷。
  - **双轨制修改**：在问卷内修改快照题时，可选择仅改快照，或同步生成题库新版本。
  - **共享与溯源**：支持将题库题目分享给其他用户，并支持查看题目被哪些问卷引用。
  - **跨问卷统计**：基于 `root_id` 和 `bank_version`，实现单道题目跨多个问卷的全局数据聚合统计。
- **详细说明**：请查看 [Phase 2 的 README 文档](./Project_1_phase2/README.md)。
- **测试报告**：请查看 [Phase 2 测试用例与结果](./Project_1_phase2/测试用例.md)。
